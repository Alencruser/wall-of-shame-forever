## 💀 Wall of Shame Forever : installation (5 min)

Chaque mort de la guilde s'affiche en jeu chez tout le monde, et part sur Discord avec une capture de ton écran de mort. Oui, c'est fait pour se moquer.

**1. L'addon**
Installe **Wall of Shame Forever** depuis CurseForge : <lien CurseForge>

**2. Le compagnon** (pour poster tes morts sur Discord)
• Télécharge le zip : <lien GitHub Releases>
• Lance `WallOfShameCompanion.exe` : il s'installe tout seul, se lance avec Windows et tourne en fond (icône Bagarre Club près de l'horloge). Tu peux supprimer le fichier téléchargé
• Windows affiche « Windows a protégé votre ordinateur » : clique **Informations complémentaires** puis **Exécuter quand même**
• Pour le désinstaller : Paramètres Windows > Applications > Wall of Shame Forever companion

**3. Le code** (uniquement tant qu'on n'a pas de guilde)
En jeu, tape `/wos code ` suivi du code épinglé dans ce salon, puis `/reload`.
Une fois dans la guilde, tu n'as plus rien à faire : le code est donné automatiquement.

**Bon à savoir**
• Joue en **fenêtré** ou **plein écran fenêtré**, sinon la capture sort noire
• `/wos striptest` vérifie que le compagnon voit bien ton écran
• Une mort pas arrivée sur Discord ? `/wos flush`, elle part (sans capture)
• Toutes les commandes : `/wos help`
• Le code ne se partage pas en dehors de la guilde 🤫
