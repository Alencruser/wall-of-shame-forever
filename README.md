# Wall of Shame Forever

WoW Forever addon: level-ups, deaths and guild roster for your guild, with your own deaths
posted to the guild's Discord.

Based on **Memento Forever** by alexauer (MIT license,
https://www.curseforge.com/wow/addons/mementoforever): English translation and extensions.
This project keeps the MIT license, see `LICENSE`.

- `WallOfShameForever/` : the addon, ready to copy into `World of Warcraft\_forever_\Interface\AddOns\`
- `companion/` : Windows program that sends your own deaths to the Discord bot
- `docs/bot-api.md` : what the bot receives
- `TODO.md` : planned features

See `WallOfShameForever/README.txt` for installation and commands.
